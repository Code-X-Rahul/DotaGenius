       - Import from `dotaconstants/build/heroes.json`, `dotaconstants/build/items.json`, `dotaconstants/build/lobby_type.json`, `dotaconstants/build/region.json`
       - CDN_BASE = "https://cdn.cloudflare.steamstatic.com"
       - `getHero(heroId: number): HeroInfo | null` -- lookup by string key, return with CDN img/icon paths
       - `getItem(itemId: number): ItemInfo | null` -- build inverted index `Record<number, ItemInfo>` at module load (items are keyed by string name, not ID). Cache it. Return null for id 0 or not found.
       - `getItemImage(itemId: number): string | null` -- shorthand for getItem(id)?.img
       - `getItemName(itemId: number): string` -- return dname or "Empty" for id 0, "Unknown Item" for missing
       - `getLobbyTypeName(lobbyType: number): string` -- from lobby_type.json, return name or "Unknown"
       - `getRegionName(cluster: number): string` -- from region.json. Note: cluster may need division/lookup. Try direct key first, fallback to empty string.

    4. Create `src/lib/match-utils.ts`:
       - Import PlayerData from match-types
       - `getTeamPlayers(players: PlayerData[])` -- returns { radiant, dire } filtered by isRadiant, sorted by playerSlot
       - `getCsAt10(lhT: number[] | null): number` -- returns lhT[10] or 0 if null/short
       - `getDnAt10(dnT: number[] | null): number` -- same for denies
       - `getLaneMatchups(players: PlayerData[])` -- groups by lane (1=bot, 2=mid, 3=top) into { [lane]: { radiant, dire } }, excludes roaming/invalid
       - `getRoamingPlayers(players: PlayerData[])` -- filters isRoaming or invalid lane
       - `buildAdvantageData(goldAdv, xpAdv)` -- converts to AdvantagePoint[], handles nulls
       - `buildPerPlayerData(players: PlayerData[])` -- builds array of { minute, player_0: gold, player_1: gold, ... } from goldT arrays
       - `benchmarkColor(pct: number | undefined): string` -- returns CSS var string based on thresholds
       - `LANE_LABELS: Record<number, string>` -- { 1: "Bot", 2: "Mid", 3: "Top" }

    5. Create `src/hooks/useFocusPlayer.ts`:
       - `useFocusPlayer()` returns `{ focusSlot: number | null, setFocus: (slot: number) => void }`
       - Clicking same slot toggles off (sets to null)

       - `tests/unit/match-utils.test.ts`: Test getTeamPlayers splitting, getCsAt10 normal + null + short, getLaneMatchups grouping, getRoamingPlayers, buildAdvantageData normal + null, benchmarkColor thresholds, buildPerPlayerData
