**Steam GC client** (`src/lib/steam-gc.ts`):
Create a module that:
- Uses `steam-user` for Steam authentication and `dota2-user` for Dota 2 GC access
- Exports `getReplaySalt(matchId: string): Promise<{ cluster: number; replaySalt: number } | null>`
- Login flow: create SteamUser instance, log in with username/password from env vars (STEAM_USERNAME, STEAM_PASSWORD), wait for 'loggedOn' event, then create Dota2Client and call requestMatchDetails
- Handle errors: login failure, GC timeout (30 second timeout), match not found
- Handle cleanup: log off Steam after request completes
- Include rate limit awareness: log a warning if approaching 100 req/24hr limit

**Spike script** (`scripts/gc-spike.ts`):
Standalone script runnable with `npx tsx scripts/gc-spike.ts <matchId>`:
- Accept a match ID as CLI argument (default to a known recent match if none provided)
- Call getReplaySalt with the match ID
- If successful: construct the replay URL using the format `http://replay{cluster}.valve.net/570/{matchId}_{replaySalt}.dem.bz2`
- Validate the URL by making a HEAD request to check if the replay is downloadable (expect 200 or 302)
- Print results: cluster, replay_salt, constructed URL, HEAD response status
- If GC fails: print error details and recommend OpenDota-only mode

**Setup guide** (`docs/steam-bot-setup.md`):
Document the steps for creating a dedicated Steam bot account:
1. Create a new Steam account at store.steampowered.com
2. Disable Steam Guard (Settings -> Account -> Manage Steam Guard)
3. Note: the account does NOT need to own Dota 2 (it's free-to-play)
4. Set STEAM_USERNAME and STEAM_PASSWORD in .env
5. Do not log into this account from the regular Steam client while the bot is running
6. Rate limit: 100 GC requests per 24 hours per account

Install tsx as a dev dependency if not already present: `npm install -D tsx`
